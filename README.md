Game Review \& Library Management System



A full-stack web application for discovering, reviewing, comparing, purchasing, and managing games through a centralized game marketplace and community platform.



The system combines marketplace functionality, user profiles, game reviews, community interaction, real-time notifications, subscriptions, recommendations, gamification, events, and administrative management.



🚀 Key Features

User registration, login, and authentication

Game marketplace with listings, categories, purchases, and reviews

User dashboard and profile management

Admin dashboard with user and listing management

Wishlist and availability notifications

Game comparison

Subscription plans and discount benefits

Real-time notifications using Socket.IO

Community forum with threads, comments, and upvotes

Events and tournament registration

Seller leaderboard

Help center and live chat support

Referral rewards

Advertisement management

AI-powered game recommendations

Multi-language support

Live streaming hub

Achievement badges and gamification

Trade escrow system

AI game coach

⚙️ Installation

Prerequisites



Make sure you have installed:



Node.js 18 or later

npm

MySQL or MariaDB

Git

1\. Clone the Repository

git clone <YOUR\_GITHUB\_REPOSITORY\_URL>

cd <YOUR\_REPOSITORY\_FOLDER>

2\. Install Backend Dependencies

npm install

3\. Install Frontend Dependencies

cd client

npm install

cd ..

4\. Set Up the Database



Create a MySQL database and import:



database.sql



The optional initial/sample data can be loaded from:



database\_seed.sql

5\. Configure Environment Variables



Create the required .env file according to the project's configuration.



Do not commit .env files or passwords/API keys to GitHub.



6\. Run the Application



Start the backend:



npm start



If the frontend is run separately during development:



cd client

npm run dev
